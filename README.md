# CareerOS Foundation

Build the frontend foundation for a modern SaaS web application called CareerOS.

PRODUCT

Name: CareerOS

Tagline:
Your AI-Powered Career Intelligence System

Description:
CareerOS is an AI-powered adaptive career intelligence platform designed for students and fresh graduates.

The long-term product will continuously analyze a user's skills, verified abilities, target career, job-market requirements, application history and interview performance to determine what the user should do next.

For this first version, DO NOT implement the AI engine, database, job APIs, resume processing, assessments, or complex backend functionality.

We are building only the polished frontend foundation.

IMPORTANT DEVELOPMENT RULES

Build a clean, production-quality SaaS frontend.

Do NOT create fake AI functionality.

Do NOT create fake job data.

Do NOT add unnecessary backend functionality.

Do NOT install unnecessary libraries.

Keep the architecture modular so backend functionality can be added later.

Make the application responsive on desktop, tablet and mobile.

Use reusable components.

Maintain consistent spacing, typography, buttons and cards throughout the application.

Avoid excessive animations.

The interface should feel trustworthy, intelligent and professional rather than flashy.

Do not make the design look like a generic AI chatbot.

Use realistic placeholder copy where backend data will eventually appear.

Clearly separate public pages from future authenticated pages.
